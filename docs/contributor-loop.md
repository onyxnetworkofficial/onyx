# Contributor loop (CL): make contributing data easy, one system for users

Tracker for the work agreed on 2026-10-29 (the owner: "start building everything"). The aim, in
the owner's and partners' words: one place, one API, one format for data users, with no provider
keys to juggle; contributors keep their own API keys and send only data; a contributor client that
works with Claude, ChatGPT and other MCP clients. Test network only. A simple token comes at
mainnet, not in this loop (no token, emission or price logic here).

Rules: every item is built in small tested steps, passes `ONYX_WEB=1 scripts/check-all.sh`, is
reviewed by hand (and by a fresh reviewer for anything that takes keys, money or data rights), is
logged here, committed and pushed to private main. Deploys: the owner's standing OK. A change that
reaches the public repository goes through `scripts/public-snapshot.sh` (no names, no label data,
neutral author, no AI co-author trailer).

Hard limits that apply to every item: a contributor's API key never leaves their machine; data
naming a person is refused; a source whose terms forbid sharing stays refused (no "the contributor
fetched it" workaround); entities only, never individuals; no real funds.

Work order: CL1, CL2, CL3, CL4, CL5, CL6, CL7, CL8.
