**What is new since v0.3.1-testnet**
- Check the newest rows. `onyx-check --bulk` now reads a newest-first page: pass `--order desc` (and `--page N` for a later page). For the first page it also proves that the page starts at the dataset's newest row (`"newestProven": true` in the report), so "newest" is no longer the node's word.
- Dates in place of keys. `--from` and `--to` take a date such as `2026-01-01` for a dataset whose key is a day.
- Follow a moved dataset. When a publisher moves a dataset to a new id, the old id answers `410` with a `successor`. `onyx-check --successor` proves that link from the publisher's own signed record and your own chain read.
- Publishers can move a dataset. `onyx-publish catalog-build` has `--move <old id>=<new id>`, `--relink` and `--unlink` to fix or take back a link, and `--links-next-generation`. Guide: `README.md` inside the publisher tools (`docs/ops/bulk-publish.md`).
- The AI connector searches the large datasets too, answers with about 10 rows and no proofs unless asked, and gives the exact `onyx-check` command for what it read.
- Freshness. Each dataset shows its newest day and a "not updated since" mark, on the website, in the API listing and in the AI connector, so stale data is never taken for current.

**Check an answer in two commands** (Linux x86-64; `onyx-check` is in `onyx-publish/bin/` of `onyx-publish-linux-x86_64.tar.gz`)

```sh
curl -s "https://onyx.cryptagraph.com/v1/bulk/onchain-archive/wbtc.mvrv/rows?order=desc&limit=5" > rows.json
onyx-check --bulk rows.json --publisher onchain-archive --dataset wbtc.mvrv --order desc --rpc https://sepolia.base.org --chain-id 84532 --book 0x04bb31d80c8ce9df02c8a03486b5812ec6e5ccc5
```

Exit 0 with `"ok": true` and `"newestProven": true`: every row is proven up to the publisher's signature, your own chain read shows the book holds it, and the page starts at the newest row.

**The Onyx desktop app** (one download, a window, no terminal)
- Windows: `onyx-desktop-windows-x64-setup.exe` (or `.msi`)
- macOS (Apple silicon and Intel): `onyx-desktop-macos-universal.dmg`
- Linux: `onyx-desktop-linux-x86_64.AppImage` or `onyx-desktop-linux-amd64.deb`

The installers are not code-signed yet. Windows SmartScreen and macOS Gatekeeper ask once before the first start; the Download page on the website shows the steps.

**Command-line downloads**
- `onyx-publish-linux-x86_64.tar.gz`: publisher tools (`onyx-publish`, `onyx-check`) for large datasets.
- `onyx-contrib-*` single-file programs (Windows, macOS, Linux): the contributor app with no Node.js install. `onyx-contrib-v0.4.0-testnet.zip` / `.tar.gz` stays for Node.js 20 or later.
- `onyx-join-linux-x86_64.tar.gz`: the observer kit for level-2 rounds. Guide: `docs/join.md`.
- `onyx-contrib-keyed-linux-x86_64.tar.gz`: `level2-keyed`, for keyed rounds.

**Check your download against `SHA256SUMS`**
- Linux: download `SHA256SUMS` into the same folder, then `sha256sum -c --ignore-missing SHA256SUMS` must say `OK` for each file you have.
- macOS: `shasum -a 256 <file>`; Windows: `certutil -hashfile <file> SHA256`. The value must equal the file's line in `SHA256SUMS`.

Try it without installing anything: https://onyx.cryptagraph.com
