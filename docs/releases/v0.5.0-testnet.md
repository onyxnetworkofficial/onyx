Test network only (Base Sepolia): no real money; tONYX and test USDC have no value; token economics are not final.

**What is new since v0.4.0-testnet**
- Apply to publish your own data. `onyx-publish` has the application tools: `apply` builds one signed application from your key, `doctor` names the step that is missing and the command for it, `verify-application` and `verify-request` check an application or a later request the way the review does, and `request` writes the signed file for a later change, such as a lost or stolen key. An application is reviewed by hand, in up to 5 days. Guide: `README.md` inside the publisher tools (`docs/ops/bulk-publish.md`).
- A Publish data page on the website: the ten steps with the guide's exact commands, what the review checks, the default grant (1 GiB, 16 datasets), what is public and what is never asked, and a status box that looks up an application or a publisher.
- Limits per publisher on a node. A node operator gives each publisher its own bytes and number of datasets, so one publisher cannot fill the node; a publisher the node does not list is refused, and a paused publisher keeps being served and can still remove a dataset.
- Usage counts with nothing about visitors. A node can count requests per route and opens per dataset per day. It keeps no access log and nothing about who asked, and no route gives the counts out.
- Dataset freshness. A node's list and each dataset say the newest day of data and how many days behind it is; the list takes `fresh=30d` and `sort=newest`.
- Backup and restore for a node, drilled: a daily backup script, and a drill that starts a node from a backup and checks it serves what the live node served.

**Start an application** (Linux x86-64; `onyx-publish` is in `onyx-publish/bin/` of `onyx-publish-linux-x86_64.tar.gz`)

```sh
tar -xzf onyx-publish-linux-x86_64.tar.gz
export PATH="$PWD/onyx-publish/bin:$PATH"
onyx-publish doctor
```

`doctor` says what to do next at every step. A download that answers `unknown command apply` is older than this release.

**The Onyx desktop app** (one download, a window, no terminal)
- Windows: `onyx-desktop-windows-x64-setup.exe` (or `.msi`)
- macOS (Apple silicon and Intel): `onyx-desktop-macos-universal.dmg`
- Linux: `onyx-desktop-linux-x86_64.AppImage` or `onyx-desktop-linux-amd64.deb`

The installers are not code-signed yet. Windows SmartScreen and macOS Gatekeeper ask once before the first start; the Download page on the website shows the steps.

**Command-line downloads**
- `onyx-publish-linux-x86_64.tar.gz`: publisher tools (`onyx-publish`, `onyx-check`) for large datasets.
- `onyx-contrib-*` single-file programs (Windows, macOS, Linux): the contributor app with no Node.js install. `onyx-contrib-v0.5.0-testnet.zip` / `.tar.gz` stays for Node.js 20 or later.
- `onyx-join-linux-x86_64.tar.gz`: the observer kit for level-2 rounds. Guide: `docs/join.md`.
- `onyx-contrib-keyed-linux-x86_64.tar.gz`: `level2-keyed`, for keyed rounds.

**Check your download against `SHA256SUMS`**
- Linux: download `SHA256SUMS` into the same folder, then `sha256sum -c --ignore-missing SHA256SUMS` must say `OK` for each file you have.
- macOS: `shasum -a 256 <file>`; Windows: `certutil -hashfile <file> SHA256`. The value must equal the file's line in `SHA256SUMS`.

Try it without installing anything: https://onyx.cryptagraph.com
