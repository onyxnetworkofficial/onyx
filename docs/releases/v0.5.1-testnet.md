**What is new since v0.5.0-testnet**
- A ready-made proof checker for macOS and Windows. `onyx-check` now comes as one file for each system, so a reader no longer needs the publisher archive or a Rust build to check an answer: `onyx-check-linux-x86_64`, `onyx-check-macos-arm64` (Apple silicon), `onyx-check-macos-x64` (Intel) and `onyx-check-windows-x64.exe`. Six steps for each system: `docs/check-a-proof.md`.
- One search order everywhere. A search that names an asset lists that asset's datasets first (a search for Bitcoin no longer mixes in Wrapped Bitcoin); a search that names none lists Bitcoin, then Ethereum, then the others. The node (`GET /v1/bulk?q=`), the website and the AI connector follow the same rule, and the node knows the same asset names as the website.
- A share of the node for each client. A node caps the requests one client holds in flight (`ONYX_MAX_INFLIGHT_PER_CLIENT`, 32 of 256 by default), so people who share one address are no longer shut out by a low connection cap.
- The hosted AI connector says what it is: everything it reads is free today, it checks nothing itself, and it lists only the tools that work on a hosted server. It asks the node which round of an observed value it holds, and calls a near match "similar" instead of "found".
- The market tool can end a market that got no value by its date (`void`), so each bet can be withdrawn.
- The daily record job and a publisher's refresh try their network stages again by themselves after a stop that passes by itself.

**Check a proof** (one file, no install)

```sh
curl -s "https://onyx.cryptagraph.com/v1/bulk/onchain-archive/btc.entity-adjusted-mvrv/rows?order=desc&limit=100" > rows.json
./onyx-check-linux-x86_64 --bulk rows.json --publisher onchain-archive --dataset btc.entity-adjusted-mvrv --order desc --rpc https://sepolia.base.org --chain-id 84532 --book 0x04bb31d80c8ce9df02c8a03486b5812ec6e5ccc5
```

It prints `"ok": true` when every row is the one its publisher signed and anchored. The proof does not show that a number is right. The files are not code-signed yet: macOS and Windows ask once before the first start (`docs/check-a-proof.md` shows the steps). The macOS and Windows files were built and type-checked by the release workflow; the Windows file was run under Wine against a live answer; neither was run on a real Mac or Windows PC before this release.

**The Onyx desktop app** (one download, a window, no terminal)
- Windows: `onyx-desktop-windows-x64-setup.exe` (or `.msi`)
- macOS (Apple silicon and Intel): `onyx-desktop-macos-universal.dmg`
- Linux: `onyx-desktop-linux-x86_64.AppImage` or `onyx-desktop-linux-amd64.deb`

The installers are not code-signed yet. Windows SmartScreen and macOS Gatekeeper ask once before the first start; the Download page on the website shows the steps.

**Command-line downloads**
- `onyx-check-*`: the proof checker by itself, one file per system (above).
- `onyx-publish-linux-x86_64.tar.gz`: publisher tools (`onyx-publish`, `onyx-check`) for large datasets.
- `onyx-contrib-*` single-file programs (Windows, macOS, Linux): the contributor app with no Node.js install. `onyx-contrib-v0.5.1-testnet.zip` / `.tar.gz` stays for Node.js 20 or later.
- `onyx-join-linux-x86_64.tar.gz`: the observer kit for level-2 rounds. Guide: `docs/join.md`.
- `onyx-contrib-keyed-linux-x86_64.tar.gz`: `level2-keyed`, for keyed rounds.

**Check your download against `SHA256SUMS`**
- Linux: download `SHA256SUMS` into the same folder, then `sha256sum -c --ignore-missing SHA256SUMS` must say `OK` for each file you have.
- macOS: `shasum -a 256 <file>`; Windows: `certutil -hashfile <file> SHA256`. The value must equal the file's line in `SHA256SUMS`.

Try it without installing anything: https://onyx.cryptagraph.com
