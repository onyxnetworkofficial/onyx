# Docker images: build and smoke test, 2026-10-13 (ROADMAP A3, Docker half of L7)

Branch `docker-smoke` from main `182dec5`; images built from commit `0615e01`. Result: **both
images build from a clean checkout and pass every smoke check** (`scripts/docker-smoke.sh`,
exit 0). Nine doc gaps were found and fixed in docs/ops. Nothing was pushed (no image, no
transaction on a public network: the chain is an in-memory anvil fork).

Setup the script adds to the documented steps, and why: the fork and both servers share the
anvil container's network namespace (the server takes `http://` node URLs to localhost only);
`ONYX_INDEX_EVERY_SECS=2` (speed); the catalog's `freshWindowSecs` stretched to 10 years (the
fixture data is older than the exported 24 h window, so its rows are free and answer 200, not 402);
a gate config with `startHeight` 971,191 (the fork holds one reserve shard, not the chain from
969,838) and absolute `fixtures`. Payments are `self-settle` with anvil's public dev key as the
operator key; no payment is made, so the servers send no transaction.

## Not verified

- The start failure with a read-only `ONYX_CAS_DIR` missing the params (gap 8) is read from the
  code (`crates/onyx-node/src/app.rs`, `FsCas::put`), not run.
- No paid request was made in the containers (the driver's own servers sell OKX's reserve row on
  the same fork); `facilitator` mode was not run in a container.
- BuildKit builds (`--memory` and `--cpuset-cpus` do not apply there: set
  `ONYX_DOCKER_BUILD_FLAGS=""`).
- systemd: only the binary names and `--check-config` in the drop-in were compared; the unit was
  not started (L7's systemd half).
- The smoke run needs network access to `https://sepolia.base.org` (fork reads) and the
  reserve tail files (`fixtures-live/tail`, git-ignored), so it cannot run in CI as is.
