# Shared hosts: names under which many unrelated people can publish, so that a
# name given up there can be taken by someone else (ADR-0066 item 4).
# One suffix a line. An origin is refused when its host is one of these, ends
# in one, or holds one as whole labels (onyx_bulk::ids::Origin::shared_host).
#
# Provenance: compiled by hand for Onyx, 2026-11-17, from each provider's own
# public naming scheme (pages hosts, app platforms, object stores and CDNs,
# tunnels, dynamic DNS, site builders, code hosts whose paths belong to their
# users). Onyx's own work, under the repository's licence. It is NOT a copy
# of, and is not derived from, the Public Suffix List: that list is under the
# Mozilla Public License 2.0, and this repository ships no copyleft material
# (deny.toml). Being listed says nothing about a provider except that names
# under it are handed out to anyone.
#
# The list is not complete and cannot be. A shared host that is missing here
# passes the tool; the reviewer reads the origin's host
# (docs/ops/publisher-review.md, line 7). To add one: add the line, keep each
# group sorted, and add a case to
# ids::tests::shared_hosts_of_the_list_and_punycode_are_refused.
